# Proyecto: Análisis de Desempleo en San Juan de Pasto (2022-2025)

Este repositorio contiene los scripts y cuadernos desarrollados para el ACA 2 de la Especialización en Analítica de Datos.

## Autores
* Marco Fidel Castro Amaya
* Brayan Yitar Portilla Pacichaná

## Contenido del Repositorio
* **`01_ETL_Limpieza_Pasto.py`**: Script en Python para la extracción, limpieza y consolidación de los microdatos de la GEIH del DANE. Filtra los registros para el departamento de Nariño (Pasto) y genera un dataset unificado eliminando duplicados.
* **`02_EDA_Modelado_Desempleo.ipynb`**: Cuaderno de Google Colab que contiene el Análisis Exploratorio de Datos (EDA), la ingeniería de características, la auditoría contra fuga de información y la batería de modelos predictivos (Regresión Logística, Random Forest y XGBoost) con validación cruzada.
